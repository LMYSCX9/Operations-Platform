# PS-08 目录结构约定

> 对应底座规格：`docs/06-non-functional-requirements.md`、ADR-0007、ADR-0012、ADR-0018、ADR-0022、ADR-0023 ｜ 契约版本：`1.2`

## 1. 插件仓库结构（建议）

```text
<plugin-repo>/
├── AGENTS.md                 # 代理规则（本模板提供）
├── plugin-spec/              # 本规范副本（整目录复制而来，保持可追溯）
├── plugin.yaml               # 插件清单（文件名固定，见 §2）
├── go.mod                    # Go 模块（若使用 Go）
├── cmd/
│   └── <plugin>/             # 入口（命令式插件即此可执行文件）
├── internal/                 # 插件内部实现，不对外暴露
├── schemas/                  # 能力输入输出结构定义
├── bin/                      # 构建产物（不入库，构建生成）
└── docs/                     # 插件自身文档（能力说明、运维手册）
```

说明：

- 若插件不使用 Go，保留 `plugin.yaml`、`schemas/`、`docs/` 结构即可，其余按语言习惯。
- `plugin-spec/` 是底座契约副本，**不要**修改其内容；底座契约升级时整体替换并记录差异。

## 2. 插件包结构（交付物）

```text
<plugin-package>/
├── plugin.yaml               # 必需：唯一清单，文件名固定
├── bin/<plugin-executable>   # 命令式插件必需；常驻插件为入口可执行文件
├── schemas/                  # 能力结构定义（必需：每个能力至少一份输入 schema）
├── lib/                      # 可选：运行时依赖
└── resources/                # 可选：静态资源
```

常驻插件额外约束：

- **本机形态（实现状态）**：契约形状为由底座以子进程方式拉起（`form: daemon` + `entry.launch`），
  但底座当前**尚未实现本机 daemon 托管**（OQ-044）；本机实例请使用命令式形态。
- 清单 `entry.socket` 只是本机 socket 文件名建议值；实际监听路径由底座生成并通过 `--ops-socket` 传入（见 [03](03-remote-protocol.md) §2）。
- **远端形态**：入口由**底座下发的 systemd unit** 拉起；插件包内同样**不得**自带 unit、init 脚本或 pid 文件模板，也不得携带证书/私钥（证书由底座在下发安装时生成并放到目标机）。
  **远端 daemon 只能经底座下发运行**，不支持也不得指导用户手工部署二进制或注册 unit。
- 包内不得包含凭据或一次性交接文件；它们只存在于运行期目录。

约束：

- 所有路径必须**相对插件包根目录**，禁止绝对路径与 `..`（防目录穿越）。
- 清单中声明的入口必须与包内实际文件一致。
- 一个插件包只含一个插件（单清单）。
- 打包格式：目录或归档，摘要校验方式见 ADR-0008（待定）。

## 3. 运行期目录

| 目录 | 归属 | 访问规则 |
| --- | --- | --- |
| 插件包目录 | 只读 | 插件可读取自身包内资源；不得写入 |
| 插件数据目录 | 读写 | 每个插件独立；不得访问其他插件目录；路径经 `--ops-data-dir` 传入 |
| 插件配置文件 | 只读 | 路径经 `--ops-config` 传入；插件不得回写 |
| 运行目录 `run/plugins/<plugin-id>/` | 底座 | 存放 `<instance-id>.sock` 与 `<instance-id>.cred`；权限 `0700`，socket `0600`。**仅本机 daemon 托管使用；该托管尚未实现（OQ-044）** |
| 临时目录 | 读写 | 调用结束前清理；不得依赖跨调用保留 |
| 底座配置/数据目录 | 禁止访问 | 插件不得直连底座存储 |

- 具体路径由底座下发（底座数据目录由配置文件指定，插件不得自行猜测或硬编码）。
- 一次性凭据文件必须读取后立即删除；不得复制到数据目录或日志。
- 卸载时数据目录的处理策略待定（建议默认保留，见底座 `docs/08-storage-and-data-directory.md` §11）。

### 3.1 远端形态在目标机上的目录（由底座创建）

以下为**目标机**侧布局，路径与具体根目录待 OQ-041，权限不得低于 ADR-0022 §6。
这些目录、配置、证书与 systemd unit **只能由底座下发创建**；不支持也不得指导用户手工部署或注册 unit。

| 对象 | 权限 | 说明 |
| --- | --- | --- |
| 插件安装目录 | 目录 `0755`、可执行文件 `0755` | 包内容，只读运行 |
| 配置文件（按主机生成） | `0600` | `--ops-config` 指向；含监听地址/端口、实例标识、配置项值 |
| 服务端证书 | `0644` | `tls/server.crt` |
| 服务端私钥 | `0600` | `tls/server.key`；不得被组/其他用户读取 |
| CA 证书 | `0644` | `tls/ca.crt`；用于校验底座客户端证书 |
| 状态目录 | `0700` | 运行期状态；不得存放私钥副本 |
| 数据目录 | 按插件需求 | 经 `--ops-data-dir` 传入；与配置、证书分离 |
| systemd unit | `0644` | 由底座下发；插件不得修改或另建 |
| 日志 | journald | 不要求插件自建日志文件 |

**禁止**：把私钥或 CA 私钥放进插件包、数据目录或日志；把配置文件放宽到 `0644`；在目标机上自行生成证书。

## 4. 命名约定

| 对象 | 约定 |
| --- | --- |
| 插件标识 | `^[a-z][a-z0-9-]*$`（小写短横线，全局唯一） |
| 能力标识 | 强制 `<插件标识>.<能力名>`，两段同规则 |
| 可执行文件名 | 小写，与插件标识一致或有明确映射 |
| schema 文件 | `<capability>.<input\|output>.json`（建议） |

## 5. 禁止事项

- 在插件包内放置密钥、证书私钥。
- 写系统目录、写自身包目录。
- 依赖当前工作目录（cwd）解析资源。
- 依赖底座源码路径。
- 在包内放置多个清单或嵌套插件。
