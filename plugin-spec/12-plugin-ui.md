## 2. 一档：声明式界面

### 2.1 能声明什么

- 入口：导航显示名、所属分组、对应的能力。
- 配置表单：由 [11](11-instance-and-config.md) 的 `config[]` 派生；可补充分组、顺序、帮助文本、占位提示。
- 动作：哪个能力对应哪个提交入口及其参数。
- 结果展示：选择底座内置展示形态（表格、键值、纯文本、结构化 JSON）与字段顺序。
- 说明文字：页面标题、说明、空状态与错误提示。

### 2.2 不能声明什么

- 不能提供 HTML、JS、CSS、模板或任何可执行内容。
- 不能声明自定义控件、脚本、表达式、条件逻辑、循环。
- 不能声明外部 URL、外部 CDN、远程图片/字体/脚本/样式。
- 不能声明权限、授予权限、改变授权判定。
- 不能绕过 CAP-02 调用网关，不能跳过高危确认（`delete`/`restore`/`gc`）。
- 不能读取敏感配置明文；敏感项只显示「已设置」。
- 不能覆盖底座导航、登录流程与全局样式。

### 2.3 清单形态（示意，字段名未定）

以下仅为**语义示意**，用于评审讨论；字段名、枚举取值与校验规则均待 OQ-011 确认，**现在写进 `plugin.yaml` 不会生效**。

```yaml
# 示意：未生效，不得照抄
ui:
  entry:
    title: "示例入口"          # 纯文本
    group: "运维"              # 底座内置分组名，待定
    capability: "demo.list"    # 必须是已声明能力
  config_form:
    groups:
      - title: "连接"
        fields: ["endpoint", "timeout_seconds"]
  actions:
    - capability: "demo.list"
      label: "查询"
  result:
    render: table              # 枚举待定：table / keyvalue / text / json
    columns: ["name", "status"]
```

### 2.4 渲染与降级

- 底座按声明渲染；数据来自实例配置与能力调用结果，不来自插件页面。
- 未识别的控件或展示类型：降级为「只读原始 JSON」并记录告警，不执行未知内容。
- 未声明 `ui` 时：底座可按能力 schema 生成最小默认视图，不影响插件安装与调用。
- 声明校验失败：按清单校验失败处理（拒绝安装并给出可定位原因），不得半渲染。

### 2.5 版本绑定

- 声明属于清单，随**插件版本**与**包摘要**一起绑定；底座记录声明摘要。
- 是否需要新的契约 MINOR 版本、以及最低契约版本要求：待 OQ-011，本文不预写版本号。
- 升级时声明整体替换；不存在「旧声明配新能力」。降级/回滚时声明随包回滚。
- 一档不产生独立静态资源，不存在资源孤儿与缓存清理问题。

### 2.6 升级、撤销与离线

| 场景 | 处理 |
| --- | --- |
| 升级 | 声明整体替换；实例配置按 [11](11-instance-and-config.md) 保留；校验失败拒绝升级 |
| 撤销/卸载 | 入口与声明随实例下线，不残留可访问页面 |
| 离线 | 渲染不依赖外网；禁止外部资源；图标只用底座内置图标名 |

### 2.7 审计与可观测

- 声明校验结果、未知类型降级、渲染失败必须写日志（插件类型、版本、失败位置）。
- 通过界面发起的调用与直接调用走同一审计路径；不记录页面点击流水。
- 界面只展示底座接口已返回的数据。

## 3. 二档：插件自带前端包（挂起，未生效）

**不要按本节实现。** 二档已挂起为 idea，不进入 v1，也不承诺未来必然实现。

若将来重启评审，需要一次性回答（当前**全部未定**，合并为 OQ-011 的单条挂起项）：

- 沙箱技术选型（iframe `sandbox` 不含 `allow-same-origin` + 独立源，或其它隔离方案）。
- Host API 最小面（调用、上下文读取、尺寸通知等；禁止读凭据、直连数据库、文件系统、SSH、任意网络）。
- 第三方前端是否需审核与签名，升级是否重新审核。
- 是否允许网络请求（默认禁止）。

即使重启，也应满足：严格 CSP、默认拒绝、与能力级授权对齐、资源随包并**留在底座侧**（不从目标机加载）、离线可用、升级与撤销可整体回收、加载与调用可审计。这些是评审门槛，不是已定设计。
