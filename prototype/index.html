远端实例

—
GET /api/plugin-instances?host_id=…
实例类型端口 三态状态 / 漂移最近探测操作
远端实例随下发创建，标识为 remote:<host>:<plugin>；三态由底座探测决定，漂移时禁止启用与调用。 探测间隔、状态过期 TTL、远端超时为可配置基线，待 OQ-047～OQ-051 确认。

下发记录

queued → connecting → uploading → verifying → installing → installed → starting → started / start_failed
创建时间插件三态状态阶段起止实例 / 证书 / 错误操作
installed / started / callable 是三个独立事实：已下发不等于已启动，更不等于可调用。 证书序列号与指纹用于指纹校验（TOFU）；证书有效期为可配置基线，待 OQ-047～OQ-051 确认。

插件管理

类型目录与实例视角（CAP-01）：类型是包与清单的抽象，实例绑定到本机或某台主机

■
实例标识：本机 local:<插件>，远端 remote:<主机>:<插件>； 三态（已安装 / 已启动 / 可调用）独立记录、互不推断，状态由底座探测决定，不采信插件自报。 证书有效期、探测间隔、状态过期 TTL、远端超时等为可配置基线，待 OQ-047～OQ-051 确认。

凭据管理

            
插件访问外部中间件所需的凭据（DOC-08 §2 C 类：最高敏感）

          

          

            
          

        


        

          存储与展示约束：凭据必须加密存储，仅在调用时按最小权限解密使用；不得进入日志、审计与错误详情；
          不提供明文导出接口，界面永不回显原值（NFR-SEC-08 / NFR-SEC-09）。凭据以 AES-256-GCM 加密存储，
          主密钥来自环境变量（优先）或配置文件独立字段，密钥不落库；防护边界为防库文件被单独拷走，不防主机被完全控制。轮换策略 TBD。
